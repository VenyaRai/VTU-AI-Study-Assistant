# 🎓 VTU AI Study Assistant

An AI-powered study assistant designed for VTU students.

## Features

-  Upload one or multiple PDF notes
-  Ask questions from the uploaded PDFs
-  Generate exam-ready answers
-  Answer formats:
  - 5 Marks
  - 6–7 Marks
  - 8 Marks
  - 10 Marks
  - Custom
-  Revision Notes
-  Viva Preparation
-  Important Questions
-  Retrieval-Augmented Generation (RAG)
-  Powered by Gemini, LangChain, FAISS, and Streamlit

## Tech Stack

- Python
- Streamlit
- LangChain
- FAISS
- Gemini API
- Git & GitHub
